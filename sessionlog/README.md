# Session logs

One file per working session: `YYYY-MM-DD-<machine>.md` (add `-2` etc. for a second
session the same day). Newest is the last one alphabetically. Keep each entry short:
what was done, what was decided, what broke, what is left. The **current** state lives in
[`../HANDOVER.md`](../HANDOVER.md); this folder is the history behind it.

Template:

```markdown
# 2026-MM-DD — <machine>

**Goal:** …
**Done:** …
**Decisions / gotchas:** …
**Left for next time:** …
**Commits:** …
```
